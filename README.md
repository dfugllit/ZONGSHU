# Tategaki — 直書劇本編輯器

**為直式書寫而設計的極簡劇本編輯器。**

Tategaki 是一款專為繁體中文與日式直書劇本格式打造的寫作工具，讓創作者能以傳統由上而下、由右至左的方式編寫劇本。

## 主要功能

- **直書排版**：支援由上而下、由右至左的劇本書寫方式。
- **場景管理**：快速建立、調整場景與場次順序。
- **角色對白**：自動處理角色名稱與對白格式。
- **動作描述**：區分場景、對白與動作文字。
- **A4 橫式列印**：適合傳統直書劇本輸出。
- **劇本封面**：支援作品名稱、編劇、版本及日期。
- **檔案備份**：支援 JSON 備份及 TXT 匯出。
- **離線使用**：不需要網路連線即可寫作。

## 下載與安裝

請前往本專案的 **Releases** 頁面，下載最新版本。

目前提供 macOS Apple Silicon 版本。

1. 下載 ZIP 壓縮檔。
2. 解壓縮取得 `Tategaki.app`。
3. 將程式移至「應用程式」資料夾。
4. 開啟 Tategaki，開始寫作。

**注意：** 目前版本尚未經過 Apple 公證，macOS 可能顯示安全性警告。請確認下載來源可信，並透過「系統設定 → 隱私權與安全性」允許開啟。
