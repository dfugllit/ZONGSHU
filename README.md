Zongshu｜縱書

為故事而寫，為直書而生。

Zongshu（縱書） 是一款專為繁體中文與日式直書劇本格式設計的極簡劇本編輯器。

採用由上而下、由右至左的傳統書寫方式，結合現代化的場景管理與排版功能，讓編劇能專注於故事本身。

主要功能

傳統直書排版：由上而下、由右至左，呈現傳統劇本的書寫形式。

智慧場景管理：快速新增、移動場景，自動處理場次編號。

角色對白編輯：區分角色名稱與對白，自動加入對白引號。

動作描述：獨立的動作文字格式，維持清楚的劇本結構。

A4 橫式排版：支援劇本列印與 PDF 輸出（透過系統列印功能）。

劇本封面：設定片名、編劇、版本、日期及製作公司。

劇本備份：支援 JSON 備份與 TXT 匯出。

離線寫作：不需網路連線即可使用。

下載與安裝

請前往本專案的 Releases 頁面下載最新版本的 Zongshu。

目前支援：

macOS Apple Silicon（M 系列晶片）

版本：v6.3

安裝方式：

下載 Zongshu_v6.3_Mac.dmg。

雙擊開啟 DMG 安裝檔。

將 Zongshu.app 拖入 Applications（應用程式）資料夾。

從「應用程式」啟動 Zongshu。

安全性提醒： 目前版本尚未經過 Apple Developer ID 簽署與公證。首次開啟時，macOS 可能顯示安全性警告。請確認檔案來自本專案的官方 Releases 頁面。

設計理念

傳統直書劇本擁有獨特的閱讀節奏與視覺結構。

Zongshu 希望保留這份書寫文化，同時提供符合現代創作者需求的編輯工具。

不需要複雜的操作，也不需要繁瑣的排版設定。

打開 Zongshu，開始寫故事。
