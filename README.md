Zongshu｜縱書劇本編輯器
版本：v6.7.1（使用說明與 README 更新）
簡介
Zongshu 是可在瀏覽器開啟的單檔 HTML 直書劇本編輯器，採 A4 橫式、日本式由上往下、由右至左的稿紙排版。劇本主要儲存在目前瀏覽器，請定期使用「備份 JSON」。
開始使用
1. 開啟 Zongshu_v6.7.1_說明文件更新.html。
2. 在上方設定劇本名稱、每頁欄數與每欄字數（參考值 20 欄 × 20 字）。
3. 透過「新增欄位」或快捷鍵建立場景、人物對白與動作描述。
4. 點選既有欄位即可編輯；雙擊場景可修改內／外景、地點及時間。
5. 完成後可匯出 TXT、備份 JSON 或列印 A4 橫式劇本。

故事大綱（v6.7.0 起的單頁規則）
- 點擊上方「故事大綱」開啟設定，可決定是否顯示大綱頁。
- 五段依右至左排列：第一幕前半、第一幕後半、第二幕前半、第二幕後半、第三幕。
- 可在設定視窗或大綱稿紙上直書輸入；文字由上往下，欄位由右至左。
- 五段合計最多 300 字，不是每段 300 字；有已使用字數提示。
- 大綱固定在單張 A4 橫式頁面，不自動產生續頁。
- 隱藏大綱頁不會刪除內容；啟用時位於登場人物頁（若顯示）之後、劇本正文之前。
- 舊版大綱若超過 300 字，不會自動刪除原文；請先備份，再縮減至上限。
- 大綱內容與顯示設定會包含在 JSON 備份中。
登場人物
點擊「登場人物」新增姓名、年齡、職業與介紹；可匯入劇本對白中的人物，並用「往前／往後」調整排序。設定欄位支援直書輸入；登場人物頁可選擇顯示或隱藏，並隨 JSON 備份保存。
場次管理與筆記
- 點選場景後，可按「場景往前移／往後移」，或「移動到第 N 場」直接輸入目的位置。
- 移動場次時，該場的對白、動作與場次筆記會一起移動；場次編號自動更新。
- 點擊場景上的「✎」或工具列「開啟場次筆記」，右側展開該場筆記。
- 筆記面板頂部顯示場次編號及場景資訊；右上角「× 關閉筆記」可收合。
- 工具列「全部筆記」可集中查看各場筆記，並開啟指定場次編輯。
- 場次筆記不會出現在正式列印中，但會包含在 JSON 備份中。
其他功能
- 「人物場次篩選」可依人物顯示符合條件的完整場次。
- 「只顯示場景」用於快速檢視場景結構。
- 「字數統計」可查看劇本字數及預估片長。
- 「封面設定」可設定片名、編劇、版本、日期與製作單位。
- 「整理換欄」可重新整理直書稿紙排版。
儲存、備份與列印
- 自動儲存：內容主要存於目前瀏覽器的本機儲存空間，換瀏覽器或清除網站資料可能無法讀取。
- 備份 JSON：保留劇本結構、人物、大綱與場次筆記等資料；建議定期備份。
- 還原 JSON：還原前先備份目前劇本，以免覆蓋現有內容。
- 匯出 TXT：輸出純文字劇本。
- 列印：使用 A4 橫式；可選擇是否包含封面、登場人物與故事大綱。
注意事項
300 字是故事大綱的輸入上限，並不保證任何字型與列印縮放設定下都絕對不溢出；建議以列印預覽確認。使用瀏覽器「列印」時請選擇 A4、橫向，並確認縮放與邊界。
